## Smart Tank (WIP)

## Materiale utilizzato:
- Arduino UNO R2 WiFi;
- Breadboard;
- Cavo seriale (Type-B maschio, Type-A maschio);
- Sensori Arduino:
  * LED RGB KY-016;
  * Ricevitore IR KY-022;
  * Bottone KY-004;
  * Sensore della temperatura KY-001 18B20;
  * Buzzer Passivo KY-006.
- 3x Resistenze da 220 Ohm;
- Raspberry Pi 2 Model B:
  * Ricevitore WiFi USB;
  * Case in plastica.
- Milesight Gateway LoRaWAN UG65;
- Sensori LoRa:
  * Sensore Ultrasuoni Milesight EM310-UDL.
